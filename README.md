# Track Dynasty — MVP 0.2.2

Unity target: **6000.5.10f1**

Mobile athletics manager prototype.

## Included

- 3-athlete starter roster
- athlete details and training focus
- scouting with sign / pass / refresh
- 7-day season loop
- Local / Regional / National / International events
- continuous 100m race animation
- race strategy selection
- cash and reputation rewards
- aging and retirement
- Hall of Fame
- IMGUI module enabled in `Packages/manifest.json`

## Run

1. Open the repository root in Unity **6000.5.10f1**.
2. Open or create any blank scene.
3. Press Play.
4. `MvpBootstrap` creates the runtime game object automatically.

## Notes

This is a code-first MVP. No backend or save system yet. The visual design reference image from the local prototype package is not required at runtime and is not included in this GitHub branch because the current GitHub connector path is text-file oriented.
